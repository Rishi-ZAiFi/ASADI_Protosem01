# Reel Script Builder

A standalone, zero-dependency web application to help short-form creators structure 30–60 second videos into a Hook, Body, and Call-To-Action (CTA).

## Features
- **Interactive UI**: Clean, responsive layout with glassmorphism design.
- **Hook & Structure Generation**: AI-like step-by-step guidance to convert an idea into a hook, body, and CTA.
- **Live Preview**: Real-time simulated 9:16 phone preview to see how the video will look.
- **Teleprompter Mode**: A built-in teleprompter to read the generated script smoothly.

## Setup & Running
This is a purely front-end application built with HTML, CSS, and vanilla JavaScript. 
It requires absolutely no dependencies, no Node.js, and no Python backend.

**To run the app:**
1. Simply double-click `index.html` to open it in your browser.
2. Or use any local HTTP server, e.g., `python3 -m http.server 8000` and visit `http://localhost:8000/`.
