# Prinetha Kannan - Portfolio Website

An interactive, dark-themed UI/UX portfolio website inspired by top product designer portfolios on **Wall of Portfolios** (Ashish Ranjan reference style).

## ✨ Features Included

1. **Preloader Intro with Animated Moving Name**:
   - Continuous kinetic marquee moving text ("PRINETHA KANNAN • UI/UX DESIGNER • KCT") with animated letter-by-letter reveal.

2. **Interactive Color Tile Grid**:
   - Responsive background grid of tiles that light up and stream vibrant glowing colors when you hover your cursor over them! Includes 3 color presets (*Cyber Neon*, *Aurora Glow*, *Sunset Gold*).

3. **Navigation Bar**:
   - Navigation links: `Home`, `About`, `Skills`, `Project`, `ProtoSem`, `Contact`.
   - Floating glassmorphism navbar with scroll spy, section indicators, and mobile responsive drawer menu.

4. **Interactive Projects Bento Grid**:
   - **Ecomon**: A real-time energy & resource monitor displaying EV charge percentage, gas cylinder fuel level, and household electricity consumption (includes interactive live sliders!).
   - **Graphic Posters**: Showcase created with Adobe Illustrator & Photoshop with modal preview lightbox.
   - **UI/UX Designs**: Product interface design showcase with modal view.
   - **Hackathons**: Highlighting participation in 3+ hackathons.

5. **ProtoSem Weekly Cards**:
   - **Week 0**: Ice breaking sessions & orientation.
   - **Week 1**: 5S implementation in Forge & portfolio building framework.

6. **About & Contact Sections**:
   - Personal bio for **Prinetha Kannan**, 3rd Year Student at **Kumaraguru College of Technology**.
   - Direct email `prinethakannan@gmail.com` with 1-click copy functionality and direct link to LinkedIn profile.

## 🚀 How to Run in VS Code

### Option 1: Using VS Code Live Server Extension (Recommended)
1. Open **VS Code**.
2. Click **File > Open Folder...** and select `prinetha-portfolio`.
3. Make sure you have the **Live Server** extension installed (by Ritwick Dey).
4. Right-click `index.html` in VS Code file explorer and click **"Open with Live Server"**.

### Option 2: Double-Click / Direct Browser
1. Open the folder `C:\Users\Prinetha Kannan\.gemini\antigravity\scratch\prinetha-portfolio`.
2. Double-click `index.html` to open it in Google Chrome, Microsoft Edge, or any modern browser.

### Option 3: Terminal (Python or Node)
Open a terminal in the folder and run:
```bash
# Using Python
python -m http.server 3000

# Using Node npx
npx serve .
```
Then visit `http://localhost:3000` in your browser!
