# Current Project Status

## Stack Overview
- **Framework:** Next.js (App Router), React 19, TypeScript (strict mode)
- **Styling:** Tailwind CSS, Lucide Icons, shadcn/ui components, next-themes
- **Backend & Database:** Supabase (Postgres, Auth, RLS) via `@supabase/supabase-js` & `@supabase/ssr`
- **AI Engine:** Google Gemini via `@google/genai` with `AIProvider` abstraction layer
- **Validation:** Zod schemas for all runtime inputs & structured AI responses
- **Testing:** Vitest & Testing Library (unit/integration), Playwright (e2e)

- **Milestone:** M0 (Recon & Scaffold) in progress.
- **Workspace State:** Empty directory initialized. Scaffolding project structure.
- **Next Steps:** Complete Next.js initialization, dependencies installation, UI tokens, env validation fallback screen, and basic setup.
